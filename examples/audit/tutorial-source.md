# Synthetic tutorial statements

These statements were written solely as test inputs for the Anaxia claim auditor. They are not quotations from an arXiv paper, evidence of a mistake in another researcher's work, or new research results.

1. For every real x, x squared minus one is nonnegative.
2. For every real x, x squared plus one is nonnegative.
3. There is no integer x for which x squared plus one equals zero.

The first statement is deliberately false; x = 0 is a counterexample. Adding one to its polynomial yields x squared, a nonnegative polynomial. The other two statements are elementary demonstrations.
